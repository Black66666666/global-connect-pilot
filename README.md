# Global Connect — пилот 0.10 / Plugin v0.1

Global Connect превращает реальный человеческий запрос в переносимую карточку, маршрутизирует её по людям и сообществам и измеряет, какой путь дал результат.

## Что работает

Пилот работает на Cloudflare Workers + D1.

- публичные карточки запросов;
- метки `ref` для каждого отдельного маршрута;
- учёт открытий и ответов;
- ответы: `могу помочь`, `знаю куда копать`, `знаю человека`, `нужно уточнение`, `не могу помочь`;
- безопасное машинное представление без публикации приватных контактов;
- MCP endpoint для ChatGPT/Codex: `/mcp`;
- переносимый пакет плагина: `plugin.json`, `mcp.json`, `skills/global-connect/SKILL.md`.

## MCP-инструменты v0.1

Без авторизации доступны:

- `list_requests` — список запросов;
- `get_request` — публичные данные одной карточки;
- `get_request_stats` — агрегированная статистика и результаты по `ref`;
- `draft_request` — подготовить карточку без сохранения.

Для приватного пилота `create_request` появляется только если MCP подключён с действующим `GC_ADMIN_TOKEN`:

`https://global-connect-pilot.biv-ai-lab.workers.dev/mcp?key=<GC_ADMIN_TOKEN>`

Ключ не хранится в репозитории. Это временная схема только для личного пилота. Перед публичным выпуском запись должна быть переведена на OAuth 2.1.

## Подключение к ChatGPT

После успешного развёртывания:

1. Проверить `/health`.
2. В ChatGPT включить режим разработчика, если он доступен для аккаунта.
3. В разделе Plugins добавить MCP-сервер.
4. Для чтения указать:

   `https://global-connect-pilot.biv-ai-lab.workers.dev/mcp`

5. Для личного теста создания карточек использовать приватный URL с `?key=<GC_ADMIN_TOKEN>`.
6. Не отправлять административный ключ в чат и не публиковать URL с ключом.

## Развёртывание

Cloudflare подключён к репозиторию `Black66666666/global-connect-pilot`.

Команда развёртывания:

`npm run deploy`

Скрипт находит существующую D1 `global-connect-pilot-db`, создаёт временный `wrangler.deploy.json` с её UUID и вызывает `wrangler deploy`.

## Публичные маршруты

Каждое размещение карточки получает отдельную обезличенную метку:

`https://<адрес>/r/<id>?ref=reddit_berlin_01`

или

`https://<адрес>/r/<id>?ref=discord_music_02`

D1 хранит метку, открытие и факт ответа. Соответствие метки конкретному внешнему каналу задаётся маршрутизатором. Приватные контакты участников не выдаются через публичный API или MCP-статистику.

## Текущая архитектура

`ChatGPT / Codex → Global Connect Plugin → MCP /mcp → Worker → D1 → публичная карточка`

Следующий слой:

`Global Connect Plugin → Social Relay → AgentMail / Reddit / Discord / Telegram`

Цель — чтобы модель могла сама создать карточку, выбрать релевантные каналы, разнести разные `ref`-ссылки, прочитать результаты и продолжить маршрут без ручного оператора там, где площадка предоставляет штатный доступ.
