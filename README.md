# Global Connect — пилот 0.9

Экспериментальная карточка запроса для проверки гипотезы: может ли короткая человеческая подсказка открыть путь, которого не нашёл цифровой поиск.

## Архитектура

Пилот работает на Cloudflare Workers + D1:

- нативный JavaScript Worker без Python/FastAPI;
- публичный HTTPS без собственного сервера;
- D1 хранит запросы, открытия и ответы;
- внешние Python-зависимости отсутствуют;
- приложение не зависит от домашнего мини-сервера.

## Развёртывание

Cloudflare подключён к репозиторию `Black66666666/global-connect-pilot`.

Команда развёртывания:

`npm run deploy`

Она вызывает обычный `wrangler deploy`.

После успешного развёртывания:

1. Добавить секрет `GC_ADMIN_TOKEN` в Settings → Variables and Secrets.
2. Открыть `/health` и убедиться, что возвращается `{"ok":true,"version":"0.9"}`.
3. Открыть `/?token=<GC_ADMIN_TOKEN>` для создания первого запроса.

## Ссылки для рассылки

Для каждого адресата используется одна карточка с обезличенной меткой:

`https://<адрес>/r/<id>?ref=R001`

В D1 хранится только `R001`. Соответствие `R001 → email` остаётся во внешней таблице рассылки.

Это позволяет посчитать:

- сколько адресатов открыли карточку;
- сколько ответили;
- какой тип помощи выбрали;
- какие подсказки реально привели к следующему результату.

## Административная часть

- `/?token=...` — создать запрос;
- `/admin?token=...` — статистика;
- `/api/r/<id>` — машинное представление карточки.

`GC_ADMIN_TOKEN` в репозитории не хранится.
